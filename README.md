# CO3519 Facial Emotion Recognition

## Overview
This repository contains the source code for my CO3519 Assessment 1 project.
It implements facial emotion recognition using LBP and HOG features with
SVM, Decision Tree, KNN, and Naive Bayes classifiers.

## How to Run
- Run in Google Colab

## Results
- Best accuracy: 65.73% (Naive Bayes + HOG, Version 4)
- KNN + HOG: ~57–59%
- SVM + LBP: ~33–36%
- Decision Tree + LBP: up to 30%

## Repository Structure
- assessment1_ai.py : source code
- Results.docx : confusion matrices and charts
- README.md : documentation
